# Code signing policy

Free code signing provided by [SignPath.io](https://about.signpath.io), certificate by [SignPath Foundation](https://signpath.org).

Only Windows binaries built from this repository's source code by its GitHub Actions workflows are signed.
Third-party libraries shipped with the plugin are not signed with this certificate.
(status right now but to be clarified)

## Team roles

- Committers and reviewers: [WarmUpTill](https://github.com/WarmUpTill)
- Approvers: [WarmUpTill](https://github.com/WarmUpTill)

Every release is approved manually before it is signed.

## Privacy policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

Features that connect to external services, such as the YouTube and Twitch integrations, only do so after the user has configured them.
The privacy policies of those services apply to the data sent to them.

- YouTube: see the [YouTube integration privacy policy](https://warmuptill.github.io/advanced-scene-switcher/privacy) and the [Google Privacy Policy](https://policies.google.com/privacy)
- Twitch: see the [Twitch privacy notice](https://www.twitch.tv/p/legal/privacy-notice/)
